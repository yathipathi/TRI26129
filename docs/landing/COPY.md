### Four Steps Section
1. **Describe**: Enter your prompt or business concept in plain words.
2. **Research**: SiteForge searches web sources and synthesizes structured facts.
3. **Edit**: Point-and-click to edit text, swap styles, lock sections, or run AI edits.
4. **Verify & Approve**: Automated browser crawl tests every button, link, and form before export.

### The Problem, Honestly
| Common Issue in AI Builders | How SiteForge Fixes It |
| :--- | :--- |
| **Invented Facts & Hallucinations** | All claims carry verified source citations or a "Needs review" flag. |
| **Broken Links & Dead Buttons** | Playwright crawl tests every link and form at 375px and 1280px viewports. |
| **AI Editing Collateral Damage** | SHA-256 byte hash verification proves non-target sections remain 100% untouched. |

### Feature Deep-Dives
1. **Verified Working**: Automated Playwright crawl testing on phone and desktop screens.
2. **Evidence-Backed Content**: Claims link to uploaded notes or web research snippets.
3. **Scoped Editing & Section Locking**: Lock sections and pin fields to prevent unintended AI overwrites.
4. **Knowledge Library for Students**: Build study guides, quizzes, flashcards, and summary pages with source citations.
5. **Human Approval Gate & ZIP Export**: 5-step checklist ensures complete control with zero vendor lock-in.

# Knowledge Library & RAG Grounding Specification

## Overview
SiteForge Knowledge Library is a zero-cost, privacy-first source repository and RAG (Retrieval-Augmented Generation) system designed for students and educators. It allows uploading study materials (notes, papers, textbook extracts, slides, web articles) to train AI section editing and generation with strict factual grounding and inline citations (`[1]`, `[2]`).

---

## 1. Supported Input Formats & Security Limits

| Format | Extension | Processing Pipeline | Security Filters |
| :--- | :--- | :--- | :--- |
| **PDF Documents** | `.pdf` | Multi-page text extraction with `/Page` boundary detection & page anchors | Magic byte check (`4d5a`, `7f454c46`, `52617221` executable/rar filter) |
| **Word Documents** | `.docx` | Paragraph text extraction & XML structure sanitization | Untrusted XML tag stripping |
| **Presentations** | `.pptx` | Slide-by-slide text layer extraction | Binary archive filter |
| **Plain Text / Markdown** | `.txt`, `.md` | Direct UTF-8 ingestion & header structure analysis | HTML/Script tag stripping |
| **Web Articles** | `.html`, URLs | Readability HTML parsing, strip `<script>` and `<style>` blocks | Origin whitelist & timeout caps |
| **Images (OCR)** | `.png`, `.jpg`, `.jpeg` | Optical character recognition layer fallback | Image MIME header validation |

### Storage & Quota Caps (Free Tier)
- **Maximum Storage Limit**: 100 MB per user account
- **Maximum File Count**: 20 uploaded documents
- **Offline Storage**: Local SQLite database with FTS5 keyword indexing + local disk storage. Zero credit card or paid API required.

---

## 2. Ingestion & Semantic Chunking Pipeline

1. **Magic Byte Security Filter**: Rejects dangerous executable binaries (`EXE`, `ELF`) and locked archives (`RAR`).
2. **Semantic Chunking Engine**:
   - Target Chunk Size: ~300 to 600 tokens per chunk.
   - Chunk Overlap: 50 tokens to preserve sentence context.
   - Page & Section Anchors: Automatically attaches `pageAnchor` (e.g., `Page 4`, `Section 2`) to every chunk.
3. **Hybrid Retrieval (BM25 + Vector Similarity)**:
   - Primary: SQLite FTS5 / local term-frequency BM25 ranking algorithm.
   - Fallback: Local sentence-transformer embeddings via `@xenova/transformers` / local vector distance calculations.

---

## 3. Strict Grounding Architecture & RAG Prompts

When RAG Grounding is enabled:
1. Untrusted source text is enclosed inside `<context_sources>` XML blocks with explicit source indices (`<source index="1">...`).
2. **Strict Mode Rule**: If user prompts request information not contained in the uploaded sources, the AI editor responds with:
   > *"Not found in your uploaded sources."*
3. **Inline Citations**: Every claim generated by the LLM contains inline numeric tags `[1]`, `[2]` linking back to the exact `sourceId`, `chunkId`, and `pageAnchor`.

## 4. Student Study Components

| Component Type | Features & Interactive Controls |
| :--- | :--- |
| **Flashcards** (`flashcards`) | 3D card flip animation, Next/Previous controls, "Mark as Known" mastery tally. |
| **Quiz** (`quiz`) | Self-assessment MCQ check, instant green/red answer reveal, explanation drawer. |
| **Glossary** (`glossary`) | Searchable key terms, auto-linked definitions, page anchor badges (`[Page 3]`). |
| **Timeline** (`timeline`) | Vertical event sequence with chronological dates and source tags. |
| **Concept Map** (`concept-map`) | Visual node graph mapping relationships between core concepts. |
| **Bibliography** (`bibliography`) | Live citation format switcher (APA 7th, MLA 9th, IEEE, Harvard). |

### Multilingual Support
Study material generation endpoint (`POST /api/study/generate`) supports instant translation to **Telugu (`te`)** and **Hindi (`hi`)**.

---

## 5. Security & Isolation Guarantee
- **Row-Level Security (RLS)**: Users can only query, edit, or delete their own uploaded knowledge sources.
- **Sandboxed Canvas**: Preview iframe operates under strict sandbox settings without `allow-same-origin` permissions.
- **Prompt Injection Defense**: Untrusted content is stripped of markdown execution blocks and delimited inside isolated system prompt contexts.
